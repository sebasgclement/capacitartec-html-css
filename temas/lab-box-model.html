Laboratorio: Modelo de caja

Padding, border, box-sizing y margin juntos: los cuatro conceptos que forman el modelo de caja, aplicados sobre una tarjeta real.

¿Qué problema resuelve?

Todo elemento HTML es una caja rectangular, y esa caja tiene cuatro capas, de adentro hacia afuera: el contenido, el padding (aire interno), el border (el borde) y el margin (aire externo, hacia los vecinos).

Sin entender estas cuatro capas, cualquier ajuste de espaciado en CSS es prueba y error. Con ellas, es una decisión: "necesito más aire adentro" es padding, "necesito separarme del vecino" es margin.

Sintaxis mínima

.tarjeta {
  padding: 16px;              /* aire interno, en las 4 direcciones */
  border: 2px solid #264de4;  /* borde visible */
  box-sizing: border-box;     /* el width ya incluye padding y border */
  margin-bottom: 16px;        /* separación con el elemento siguiente */
}

El detalle que más confunde: sin box-sizing: border-box, el width que declarás es solo el del contenido, y el padding y el border se suman por afuera, agrandando la caja real. Con border-box, el width que pusiste es el ancho final, sin sorpresas.

Resultado

Errores comunes

  • Confundir padding con margin Si el fondo de color de la caja se agranda, es padding. Si lo que se mueve es la separación con el vecino sin que la caja cambie de tamaño, es margin.
  • Poner border sin border-style border-width: 2px; sola no dibuja nada: por defecto el estilo es none. Hace falta solid, dashed, etc. El atajo border: 2px solid #000; ya lo incluye.
  • Olvidar box-sizing y after fijar un width Con content-box (el valor por defecto), agregar padding o border después de fijar el width agranda la caja real, aunque el CSS diga otra medida.
  • Usar margin cuando el problema es alineación Empujar una caja con márgenes a mano para "centrarla" es fragil. Para centrar de verdad, mejor Flexbox o Grid (los vas a ver más adelante).

Cuándo NO usarlo

✔ box-sizing: border-box

Casi siempre. Es tan común que muchos proyectos lo aplican a * una sola vez, al principio del CSS, y se olvidan del tema.

✘ content-box (el default)

Rara vez conviene dejarlo así a propósito: es el que obliga a recalcular a mano cada vez que cambiás un padding.

Mini-ejercicio

Sobre el editor de arriba, después de resolver el laboratorio:

  1. Cambiá el border a dashed y de otro color.
  2. Subí el padding a 24px y mirá cómo crece la caja.
  3. Sacá box-sizing: border-box del * y volvé a ponerlo solo en .tarjeta: el resultado visual no cambia, pero ahora sabés exactamente qué elemento lo tiene.
