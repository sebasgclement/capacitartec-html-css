Creando un Grid

Filas, columnas y el vocabulario que vas a usar en los otros once temas: pistas, líneas, celdas y gap.

¿Qué problema resuelve?

Ya sabés que display: grid arma una grilla. Ahora falta lo importante: decidir cuántas filas y columnas tiene, y qué tamaño.

Sin eso, Grid te da una sola columna del ancho del contenedor y apila todo hacia abajo, que no es muy distinto a no hacer nada.

Además hay tres palabras que conviene aprender ahora, porque toda la documentación las usa:

  • Pista (track): una fila o una columna completa.
  • Línea: el borde entre pistas. Se numeran desde 1, y las líneas son una más que las pistas.
  • Celda: el cruce de una fila con una columna. La unidad mínima.

Sintaxis mínima

.contenedor {
  display: grid;

  grid-template-columns: 150px 150px 150px;  /* 3 columnas de 150px */
  grid-template-rows: 100px 100px;           /* 2 filas de 100px */

  gap: 10px;              /* separación en filas y columnas */
  /* column-gap: 10px;  row-gap: 20px;  → por separado */
}

Cada valor que escribís en grid-template-columns es una columna. Tres valores, tres columnas. Es literal, y es lo que hace a Grid tan legible.

Con 3 columnas y 2 filas tenés 6 celdas. Los hijos las van ocupando en orden, de izquierda a derecha y de arriba hacia abajo.

Errores comunes

  • Separar los valores con comas Se escriben con espacios: 150px 150px, no 150px, 150px. Con coma la propiedad entera se ignora.
  • Definir más celdas que elementos Si declarás 6 celdas y ponés 4 hijos, las 2 últimas quedan vacías. No es un error de CSS, pero suele no ser lo que querías.
  • Poner medidas fijas en px y esperar que sea responsive 150px 150px 150px siempre mide 450px, se desborde o no. Para que se adapte necesitás fr (tema 3).
  • Contar las líneas desde 0 La primera línea es la 1, no la 0. Con 3 columnas hay 4 líneas verticales. Esto importa mucho en el tema 7.

Cuándo NO usarlo

✔ Declará las filas

Cuando el alto importa: un hero de pantalla completa, un dashboard con zonas de tamaño fijo, una galería de cuadrados.

✘ Dejá que las calcule Grid

Cuando el contenido manda: un listado de artículos de largo variable. Fijar el alto ahí te corta el texto o te deja huecos.

En la práctica, grid-template-columns se usa casi siempre y grid-template-rows bastante menos: las filas suelen crecer solas según lo que tengan adentro.

Mini-ejercicio

Armá un calendario semanal de juguete:

  1. 7 columnas de 60px (una por día).
  2. 3 filas de 50px.
  3. Separación de 4px entre columnas y 8px entre filas.
Ver solución 
.contenedor {
  display: grid;
  grid-template-columns: 60px 60px 60px 60px 60px 60px 60px;
  grid-template-rows: 50px 50px 50px;
  column-gap: 4px;
  row-gap: 8px;
}

Escribir 60px siete veces cansa, ¿no? Para eso existe repeat(7, 60px), que vemos en el tema 4.

gap: 8px 4px es el atajo de las dos propiedades juntas: primero filas, después columnas.
