Introducción a CSS Grid

El primer sistema de CSS pensado para armar layouts en dos dimensiones: filas y columnas al mismo tiempo.

¿Qué problema resuelve?

Durante años armamos layouts con herramientas que no estaban hechas para eso: float (pensado para que el texto rodee una imagen) y hasta <table> (pensado para datos). Funcionaban, pero pedían clearfix, anchos calculados a mano y muchos div extra.

Flexbox mejoró mucho las cosas, pero trabaja en una sola dirección: o acomodás en fila, o acomodás en columna. Cuando querés que además las cosas se alineen hacia abajo, empezás a pelear con anchos y márgenes.

Grid resuelve exactamente eso: definís una grilla de filas y columnas, y los elementos se ubican en ella. Vos declarás la estructura, no las medidas de cada pieza.

Sintaxis mínima

Tres propiedades y ya tenés una grilla funcionando:

.contenedor {
  display: grid;
  grid-template-columns: 200px 200px 200px;  /* 3 columnas */
  gap: 12px;                                 /* separación */
}

Todo se declara en el contenedor. Los hijos directos se convierten automáticamente en ítems de la grilla y se van acomodando solos, sin que tengas que tocarles nada.

Errores comunes

  • Poner display: grid en el hijo Va siempre en el contenedor. Si lo ponés en la caja, convertís a esa caja en una grilla para sus hijos, que no es lo que buscabas.
  • Esperar que funcione con nietos Grid solo afecta a los hijos directos. Si envolvés cada caja en otro div, la grilla acomoda los envoltorios, no las cajas.
  • Seguir usando margin para separar Para eso está gap. Es más simple y no agrega espacio sobrante en los bordes de la grilla.
  • Creer que Grid reemplaza a Flexbox Son complementarios y se usan juntos todo el tiempo: Grid para la estructura de la página, Flexbox para alinear el contenido dentro de cada parte.

Cuándo NO usarlo

✔ Usá Grid

Cuando la estructura importa en las dos direcciones: layout de página, galerías, dashboards, formularios de varias columnas.

✘ Mejor Flexbox

Cuando es una sola línea de elementos: una barra de navegación, un grupo de botones, un ítem con ícono y texto al lado.

Regla práctica: si podés describir lo que querés diciendo "una fila de..." o "una columna de...", es Flexbox. Si necesitás decir "una cuadrícula de...", es Grid.

Mini-ejercicio

Sobre el editor de arriba:

  1. Hacé que la grilla tenga 2 columnas en vez de 3.
  2. Separá las cajas 24px entre sí.
  3. Agregá una séptima caja y fijate dónde cae sin que le digas nada.
Ver solución 
.contenedor {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 24px;
}

La caja 7 arranca sola una cuarta fila. Nunca declaraste filas: Grid las va creando a medida que hacen falta. Eso se llama grid implícito y lo vemos en el tema 5.
