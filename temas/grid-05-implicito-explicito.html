Grid implícito y explícito

Qué pasa cuando hay más elementos que celdas declaradas, y cómo controlar las pistas que Grid inventa por su cuenta.

¿Qué problema resuelve?

En el tema 1 pasó algo raro: declaraste 2 columnas, pusiste 7 cajas, y las que sobraban se acomodaron igual en filas nuevas que vos nunca escribiste.

Eso no es magia: es el grid implícito. Grid nunca deja un elemento afuera. Si no hay celda para él, crea la pista que haga falta.

La diferencia importa porque cada uno se controla con propiedades distintas:

  • Explícito: lo que vos declaraste con grid-template-columns y grid-template-rows.
  • Implícito: lo que Grid agregó solo. Se controla con grid-auto-rows y grid-auto-columns.

El síntoma típico de no saber esto: "le puse alto a las filas pero de la tercera para abajo lo ignora". Claro: la tercera fila es implícita, y grid-template-rows no la alcanza.

Sintaxis mínima

.contenedor {
  display: grid;

  /* EXPLÍCITO: lo que vos declarás */
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 100px;        /* solo la primera fila */

  /* IMPLÍCITO: el molde de las filas que Grid cree después */
  grid-auto-rows: 60px;

  /* Y en qué dirección las crea */
  grid-auto-flow: row;       /* row (por defecto) | column */
}

Con eso, la fila 1 mide 100px y todas las que sigan miden 60px, haya 2 o 200.

El valor más útil para grid-auto-rows suele ser minmax(100px, auto): un piso, pero libertad para crecer si el contenido lo necesita.

Errores comunes

  • Querer estilar filas implícitas con grid-template-rows No las alcanza. Si no sabés cuántas filas va a haber (un listado que viene de una base de datos), lo que necesitás es grid-auto-rows.
  • Filas implícitas que quedan en auto Es el valor por defecto: cada fila mide lo que su contenido más alto. Por eso a veces te quedan filas de alturas desparejas sin entender por qué.
  • Confundir grid-auto-flow: column con cambiar las columnas No modifica grid-template-columns: cambia el orden en que se llenan las celdas, de arriba hacia abajo en vez de izquierda a derecha.
  • Crear filas implícitas sin querer Si posicionás un elemento en la fila 5 de una grilla de 3 filas (tema 7), Grid crea las filas 4 y 5 vacías. A veces aparece un hueco enorme y la causa es esta.

Cuándo NO usarlo

✔ Dejá que sea implícito

Cuando la cantidad de elementos es variable o desconocida: un listado de productos, comentarios, resultados de búsqueda.

✘ Declaralo explícito

Cuando el layout es fijo y conocido: el esqueleto de una página con header, contenido y footer. Ahí querés control total.

Buena costumbre: si el contenido es dinámico, poné siempre un grid-auto-rows. Te ahorra sorpresas cuando llegan datos distintos a los que probaste.

Mini-ejercicio

Un listado de novedades:

  1. 2 columnas iguales.
  2. La primera fila destacada, de 150px.
  3. Todas las demás, mínimo 80px pero que puedan crecer.
Ver solución 
.novedades {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  grid-template-rows: 150px;              /* explícita: solo la 1ª */
  grid-auto-rows: minmax(80px, auto);     /* implícitas: el resto */
  gap: 12px;
}

Declarar una sola fila en grid-template-rows es totalmente válido y muy común: definís la que es especial y dejás que el resto se genere solo con el molde de grid-auto-rows.
