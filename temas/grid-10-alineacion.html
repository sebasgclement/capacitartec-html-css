Alineación con Grid

Seis propiedades que se confunden entre sí, ordenadas de una vez por todas con una sola regla para acordarse.

¿Qué problema resuelve?

Ya sabés armar la grilla. Falta lo último: dónde se para el contenido adentro de cada celda, y dónde se para la grilla entera adentro del contenedor cuando le sobra espacio.

Son dos preguntas distintas y por eso hay dos familias de propiedades. La mayoría del lío viene de mezclarlas.

La regla para no perderse:

  • justify-* → eje horizontal (columnas, ↔)
  • align-* → eje vertical (filas, ↕)
  • *-items → mueve el contenido dentro de sus celdas
  • *-content → mueve la grilla entera dentro del contenedor
  • *-self → igual que items, pero para un solo hijo

Combinando esas piezas salen las seis: justify-items, align-items, justify-content, align-content, justify-self, align-self.

Dato importante: *-content solo hace algo si sobra espacio. Con 1fr nunca sobra, así que no vas a ver ningún efecto. Es la causa número uno de "puse justify-content y no pasa nada".

Sintaxis mínima

.contenedor {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  height: 400px;

  /* Contenido DENTRO de cada celda */
  justify-items: center;   /* start | end | center | stretch (default) */
  align-items: center;

  /* La GRILLA dentro del contenedor (necesita espacio sobrante) */
  justify-content: center; /* start | end | center | space-between |
                                    space-around | space-evenly */
  align-content: center;
}

/* Un hijo puntual, distinto al resto */
.especial {
  justify-self: end;
  align-self: start;
}

/* Atajos */
place-items: center;        /* align-items + justify-items */
place-content: center;      /* align-content + justify-content */
place-self: center;         /* align-self + justify-self */

place-items: center es el famoso "centrar cualquier cosa en dos líneas de CSS": 

.centrado {
  display: grid;
  place-items: center;
}

Resultado

La línea punteada es el contenedor. Cambiá justify-items a center (las cajas se achican en su celda) y después justify-content a center (se mueve el bloque entero). Ahí se ve la diferencia de una vez.

Errores comunes

  • Usar *-content con columnas 1fr Con 1fr las pistas se comen todo el espacio, así que no sobra nada y justify-content no tiene efecto. Necesitás medidas fijas (100px, auto) para ver la diferencia.
  • Esperar que align-content funcione sin altura Si el contenedor no tiene height ni min-height, mide exactamente lo que su contenido: no hay espacio vertical sobrante para repartir.
  • Confundir justify con align En Grid es fijo: justify siempre es horizontal y align siempre vertical. (En Flexbox depende de flex-direction, y de ahí viene la confusión.)
  • Usar justify-self en el contenedor Las tres propiedades *-self van en el hijo. En el contenedor no hacen nada.
  • Pelear con stretch sin saberlo Es el valor por defecto de *-items: por eso las cajas ocupan toda su celda aunque no se lo hayas pedido.

Cuándo NO usarlo

✔ Alineá con Grid

Para centrar un elemento en un contenedor (place-items: center) o alinear el contenido de las celdas de una grilla.

✘ Usá Flexbox adentro

Para alinear varios elementos dentro de una misma celda: un ícono y su texto, una fila de botones al pie de una tarjeta.

Es el patrón más común en producción: Grid alinea las celdas entre sí, Flexbox alinea lo que hay adentro de cada una.

Mini-ejercicio

Tres situaciones, tres soluciones:

  1. Centrar un cartel de "Cargando…" en el centro exacto de la pantalla.
  2. Una grilla de 3 columnas de 100px centrada horizontalmente en un contenedor ancho.
  3. Que solo la última caja se pegue a la derecha de su celda.
Ver solución 
/* 1 */
.pantalla {
  display: grid;
  place-items: center;
  min-height: 100vh;     /* sin altura no hay nada que centrar */
}

/* 2 */
.grilla {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  justify-content: center;   /* funciona porque las columnas son fijas */
}

/* 3 */
.grilla > :last-child {
  justify-self: end;
}

En el caso 2, si cambiaras 100px por 1fr, el justify-content dejaría de hacer efecto: no sobraría espacio.
