Repeat y Minmax

Dos funciones que evitan repetir código y le ponen límites a las pistas. Juntas son la base del grid responsive.

¿Qué problema resuelve?

En el tema 2 escribiste esto para un calendario: 

grid-template-columns: 60px 60px 60px 60px 60px 60px 60px;

Funciona, pero es tedioso de escribir y peor de mantener: si mañana querés 65px, tenés que cambiar siete valores sin olvidarte de ninguno. repeat() resuelve eso.

El segundo problema es distinto. 1fr se adapta, pero sin límites: en un monitor ancho una columna de texto puede estirarse a 900px y volverse ilegible; en un celular puede achicarse tanto que las palabras se rompen. minmax() te deja decir "flexible, pero nunca menos de esto ni más de aquello".

Sintaxis mínima

/* repeat(cantidad, tamaño) */
grid-template-columns: repeat(7, 60px);
grid-template-columns: repeat(3, 1fr);

/* Se puede combinar con valores sueltos */
grid-template-columns: 250px repeat(3, 1fr) 100px;

/* repeat también acepta varios tamaños que se alternan */
grid-template-columns: repeat(2, 1fr 2fr);   /* = 1fr 2fr 1fr 2fr */

/* minmax(mínimo, máximo) */
grid-template-columns: minmax(200px, 1fr) 2fr;

/* El truco más útil de todo Grid */
grid-template-columns: minmax(0, 1fr) 1fr;

Ese último merece una explicación: por defecto una pista 1fr no puede achicarse más de lo que mide su contenido. Con minmax(0, 1fr) le decís "podés llegar hasta cero", y así se acaban los desbordes misteriosos.

Errores comunes

  • Poner el fr en el mínimo minmax(1fr, 300px) no es válido: fr solo puede ir en el máximo. El mínimo tiene que ser una medida concreta, auto o min-content.
  • Mínimos demasiado grandes repeat(4, minmax(300px, 1fr)) exige 1200px más los gaps. En una pantalla más chica la grilla se desborda: el mínimo gana siempre.
  • Olvidar minmax(0, 1fr) con contenido ancho Si adentro tenés una imagen grande, un <pre> o una tabla, la columna se niega a achicarse. Este es el arreglo, y casi nadie lo conoce hasta que lo sufre.
  • Escribir repeat con coma de más Es repeat(3, 1fr): la coma va solo entre la cantidad y el tamaño. repeat(3, 1fr, 2fr) es inválido; lo correcto es repeat(3, 1fr 2fr).

Cuándo NO usarlo

✔ Usá repeat

Cuando las pistas se repiten con un patrón: galerías, calendarios, grillas de productos, cualquier cosa de N columnas iguales.

✘ Escribilas a mano

Cuando cada pista es distinta: 250px 1fr 300px se lee mejor así que forzando un repeat().

Con dos o tres columnas distintas, escribirlas es más claro. A partir de cuatro iguales, repeat() gana siempre.

Mini-ejercicio

Una galería de fotos que se porte bien:

  1. 4 columnas, usando repeat().
  2. Cada una nunca menor a 120px pero flexible hacia arriba.
  3. Filas de alto mínimo 100px, que crezcan si el contenido lo pide.
Ver solución 
.galeria {
  display: grid;
  grid-template-columns: repeat(4, minmax(120px, 1fr));
  grid-auto-rows: minmax(100px, auto);
  gap: 10px;
}

grid-auto-rows es para las filas que Grid crea solo, que es justo lo que pasa en una galería: no sabés cuántas fotos va a haber. Lo vemos en detalle en el tema 5.

Ojo: con 4 columnas de mínimo 120px, abajo de ~520px se desborda. La solución de verdad es auto-fit, y es el tema 6.
