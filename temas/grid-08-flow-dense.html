Grid flow: dense

Cómo tapar los huecos que quedan cuando mezclás elementos de distintos tamaños, y por qué a veces conviene no taparlos.

¿Qué problema resuelve?

En el tema 7 posicionaste elementos a mano. Si probaste un poco, seguro viste esto: una tarjeta que ocupa 2 columnas no entra al final de una fila, así que salta a la siguiente y deja un hueco atrás.

Por defecto Grid acomoda los elementos en orden y nunca retrocede. Si un elemento no entra, avanza; y si más adelante aparece uno chico que sí habría entrado en el hueco, no vuelve a buscarlo.

grid-auto-flow: dense cambia esa regla: le permite a Grid volver atrás y rellenar los huecos con los elementos chicos que vengan después.

Es la diferencia entre una galería con agujeros y una galería compacta tipo mosaico.

Sintaxis mínima

.contenedor {
  display: grid;
  grid-template-columns: repeat(4, 1fr);

  grid-auto-flow: row dense;
  /* row    → llena por filas (por defecto) */
  /* column → llena por columnas */
  /* dense  → además, rellena huecos hacia atrás */
}

dense es un modificador: se escribe junto a row o column. Escribir solo grid-auto-flow: dense equivale a row dense.

Errores comunes

  • Romper el orden de lectura Este es el problema serio de dense: cambia el orden visual pero no el del HTML. Alguien navegando con teclado o con lector de pantalla recorre el orden original, que ya no coincide con lo que se ve.
  • Usarlo cuando el orden tiene significado En un listado cronológico, un ranking o los pasos de un instructivo, dense puede dejar el ítem 7 antes que el 5. Ahí es un bug, no una mejora.
  • Escribirlo solo grid-auto-flow: dense funciona, pero es más claro escribir row dense o column dense para que se lea la dirección.
  • Esperar que ordene por tamaño dense no reordena buscando el mejor encastre global: recorre los elementos en orden y mete cada uno en el primer hueco donde entre.

Cuándo NO usarlo

✔ Usá dense

Cuando el orden da igual y lo que importa es que se vea compacto: galerías de fotos, mosaicos de logos, nubes de tags.

✘ Evitá dense

Cuando el orden comunica algo: resultados de búsqueda por relevancia, publicaciones por fecha, pasos numerados, un podio.

La pregunta para decidir: ¿alguien podría quejarse de que el elemento 5 aparezca después del 7? Si la respuesta es sí, no uses dense.

Mini-ejercicio

Sobre el editor de arriba:

  1. Activá dense y contá cuántos huecos quedan.
  2. Cambiá .ancha a span 4. ¿dense puede rellenar algo ahí?
  3. Probá grid-auto-flow: column dense. ¿Qué cambió?
Ver solución

1. Con dense los huecos de la primera fila se llenan con las cajas chicas que venían después.

2. Con span 4 la caja ancha ocupa la fila entera, así que no deja hueco al costado: dense no tiene nada que rellenar ahí. Un buen recordatorio de que dense solo ayuda cuando los huecos existen.

3. Con column el llenado pasa a ser de arriba hacia abajo y después a la derecha. El orden visual cambia completamente, y ahí se nota mejor por qué el orden de lectura es un tema. 

.mosaico { grid-auto-flow: row dense; }
