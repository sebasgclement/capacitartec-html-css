Imágenes y multimedia fluida

  • img { max-width: 100%; height: auto; } — nunca desborda, mantiene proporción.
  • .contenedor { aspect-ratio: 16 / 9; } — reserva espacio para video/iframe antes de que carguen.
  • srcset="foto-480.jpg 480w, foto-1200.jpg 1200w" + sizes="(max-width:600px) 90vw, 600px" — el navegador elige la variante más liviana que alcanza.
  • <picture><source media="..."><source type="..."><img></picture> — recorte distinto (art direction) o formato con fallback.

Media queries

  • @media (min-width: 600px) { ... } — mobile first: agregar, nunca corregir.
  • @media (prefers-color-scheme: dark|light) — preferencia de tema del sistema.
  • @media (prefers-reduced-motion: reduce) — desactivar animaciones si la persona lo pidió.
  • Evitar mezclar min-width y max-width para el mismo breakpoint en un mismo proyecto.

Patrón mobile-first:

.grid { grid-template-columns: 1fr; }              /* base: celular */
@media (min-width: 600px) { .grid { grid-template-columns: repeat(2,1fr); } }
@media (min-width: 900px) { .grid { grid-template-columns: repeat(3,1fr); } }

Layouts que se reordenan (Holy Grail)

  • Base (sin media query): grid-template-areas apilado en una sola columna.
  • A partir de un breakpoint: se redibuja el mismo grid-template-areas con más columnas.
  • El orden del HTML debe seguir siendo lógico para navegación por teclado en cualquiera de los dos casos.

Feature queries (@supports)

  • @supports (display: grid) { ... } — aplica una mejora solo si el navegador la soporta.
  • @supports not (...), and, or — se combinan como en las media queries.
  • Siempre necesita una base funcional por fuera del @supports: es para sumar, no para ser la única fuente de estilos.
  • CSS.supports("display", "grid") — la misma pregunta, pero desde JavaScript.

Container queries

  • .wrap { container-type: inline-size; } — declara el ancestro que se va a medir.
  • @container (min-width: 380px) { ... } — reacciona al ancho del contenedor, no del viewport.
  • container-name — para apuntar a un contenedor específico si hay varios anidados.
  • Media query = pantalla completa. Container query = el espacio real del componente.

Cheat express: ¿cuál uso?

  • Imagen que se achica → max-width: 100%; height: auto;
  • Misma foto, distinto peso → srcset + sizes
  • Recorte distinto según pantalla → <picture>
  • Layout de toda la página → @media
  • Un componente reutilizable → @container
  • CSS muy nuevo, con fallback → @supports
