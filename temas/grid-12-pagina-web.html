Creando una página web

El cierre del módulo: los once temas anteriores puestos a trabajar juntos en una página completa y responsive.

¿Qué problema resuelve?

Cada tema anterior mostró una pieza aislada. En un proyecto real todas aparecen a la vez, y lo difícil no es cada una por separado sino decidir cuál usar en cada parte.

Esta es la guía de decisión que vas a repetir en todos tus proyectos:

  • Esqueleto de la página → grid-template-areas (tema 9)
  • Galerías y listados → auto-fit + minmax (tema 6)
  • Piezas destacadas → grid-column: span (tema 7)
  • Alinear tarjetas entre sí → subgrid (tema 11)
  • Contenido dentro de una celda → Flexbox, no Grid
  • Cambio de layout en celular → redibujar las areas

La regla de fondo: Grid para la estructura, Flexbox para el contenido. Casi todo lo demás sale de ahí.

Sintaxis mínima

El esqueleto completo de una página, en 20 líneas:

body {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "aside   main"
    "footer  footer";
  min-height: 100vh;      /* que el footer quede abajo de todo */
  gap: 16px;
}

header { grid-area: header; }
aside  { grid-area: aside; }
main   { grid-area: main; }
footer { grid-area: footer; }

@media (max-width: 700px) {
  body {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "main"
      "aside"
      "footer";
  }
}

El 1fr en la fila del medio es lo que empuja el footer al fondo aunque haya poco contenido. Junto con min-height: 100vh reemplaza todos los trucos de "sticky footer" que se usaban antes.

Y en celular, el main pasa antes que el aside aunque en el HTML esté después. El orden del documento sigue siendo el correcto para lectores de pantalla.

Errores comunes

  • Usar Grid para todo Una barra de navegación con logo y links es una fila: eso es Flexbox. Meter Grid ahí es más código para el mismo resultado.
  • Anidar grids sin necesidad Antes de agregar otro display: grid, preguntate si no alcanza con span en el grid que ya tenés.
  • Olvidar min-height: 100vh Sin eso, en una página con poco contenido el footer queda flotando en el medio de la pantalla.
  • Reordenar visualmente sin pensar en el teclado Cambiar el orden con areas no cambia el orden de tabulación. Si el resultado visual se aleja mucho del HTML, arreglá el HTML.
  • Media queries de más Si la galería ya usa auto-fit, no necesita breakpoints propios. Reservá las media queries para cuando cambia la estructura, no la cantidad.

Cuándo NO usarlo

✔ Grid

El esqueleto de la página, galerías, dashboards, cualquier cosa bidimensional o con piezas de distinto tamaño.

✘ Flexbox

Navbars, grupos de botones, ícono + texto, el pie de una tarjeta, cualquier fila o columna simple.

No son competidores. En la demo de arriba, el layout es Grid y adentro de cada tarjeta lo natural sería Flexbox. Casi todos los sitios reales usan los dos, y saber cuándo va cada uno es más valioso que dominar todas las propiedades de memoria.

Mini-ejercicio

Integrador del módulo. Armá una página de portfolio con:

  1. Header de ancho completo y footer siempre abajo.
  2. Una barra lateral de 200px que en celular pase debajo del contenido.
  3. Una galería de proyectos con tarjetas de mínimo 200px, sin media queries propias.
  4. El primer proyecto destacado, ocupando el doble de ancho.
Ver solución 
body {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "aside  main"
    "footer footer";
  min-height: 100vh;
  gap: 20px;
}

header { grid-area: header; }
aside  { grid-area: aside; }
main   { grid-area: main; }
footer { grid-area: footer; }

.proyectos {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(200px, 100%), 1fr));
  gap: 16px;
}

.proyecto:first-child { grid-column: span 2; }

@media (max-width: 700px) {
  body {
    grid-template-columns: 1fr;
    grid-template-areas: "header" "main" "aside" "footer";
  }
  /* en una sola columna, el destacado no puede ocupar 2 */
  .proyecto:first-child { grid-column: auto; }
}

Ese último detalle es el que más se olvida: cuando la galería queda en una sola columna, un span 2 fuerza una segunda columna implícita y se desborda. Hay que devolverlo a auto.

Con esto usaste areas (9), auto-fit + minmax (6), span (7), grid implícito (5) y fr (3) en un solo archivo. Eso es el módulo completo.
