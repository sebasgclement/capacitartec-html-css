Mobile First

No es una técnica nueva de CSS: es un orden de trabajo. Empezar por el celular cambia cómo se escriben las media queries — y para mejor.

¿Qué problema resuelve?

Diseñar primero para escritorio y después "achicar para celular" con @media (max-width: ...) suena razonable, pero en la práctica genera un problema: cada regla de escritorio tiene que ser anulada más abajo en el CSS para que el celular se vea bien. El código crece en las dos direcciones y las especificidades empiezan a pelear entre sí.

Mobile first da vuelta el orden: el CSS base (sin ninguna media query) es el de la pantalla más chica. Cada @media (min-width: ...) que sigue no anula nada, solo agrega mejoras a medida que hay más espacio disponible. Es la misma sintaxis de min-width que ya viste, pero con esta disciplina de "agregar, no corregir".

Sintaxis mínima

/* Base: se aplica siempre, pensado para el celular */
.hero { padding: 16px; }
.grid { display: grid; grid-template-columns: 1fr; gap: 12px; }

/* Mejora progresiva a partir de 600px */
@media (min-width: 600px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}

/* Otra mejora a partir de 900px */
@media (min-width: 900px) {
  .grid { grid-template-columns: repeat(3, 1fr); }
  .hero { display: flex; align-items: center; justify-content: space-between; }
}

Notá que ninguna regla dentro de una media query revierte algo de la base — solo suma comportamiento nuevo. Esa es la señal de que el enfoque mobile-first está bien aplicado.

Errores comunes

  • Escribir el CSS de escritorio primero "por costumbre" Es fácil recaer en max-width porque es como se enseñaba antes. La pregunta que ayuda a decidir: "¿esta regla es la base universal, o es una mejora que solo tiene sentido con más espacio?"
  • Anular en vez de agregar Si dentro de un @media (min-width: ...) estás escribiendo display: block !important para deshacer algo del flex de la base, es señal de que el orden se invirtió en algún punto.
  • Cargar recursos pesados "porque total en desktop hay ancho de banda" Mobile first también aplica al peso: si la base carga una imagen gigante pensando en escritorio, todos los celulares la bajan igual, aunque nunca la muestren tan grande. Repasá el tema de srcset.

Cuándo NO usarlo

✔ Mobile first

Casi cualquier sitio o app nueva. La mayoría del tráfico web global es móvil, y el enfoque produce CSS más simple de mantener.

✘ Desktop first (excepción)

Herramientas internas de uso exclusivo en escritorio (paneles de administración muy densos en datos, por ejemplo), donde el uso en celular directamente no está contemplado.
